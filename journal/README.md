# 공부 일지

매일 공부한 내용을 짧게 기록합니다. **정리된 글이 아니라 날것의 기록**이므로 5~10분 안에 씁니다. 잘 정리하고 싶은 개념은 [notes/](../notes/)에 따로 노트로 만듭니다.

| | journal (일지) | notes (노트) |
|---|---|---|
| 목적 | 꾸준함과 과정의 기록 | 개념의 정리 |
| 단위 | 하루 | 개념 하나 |
| 완성도 | 날것 그대로 | 다시 봐도 이해되게 |

## 규칙

- **파일 위치**: `journal/연도/연도-월-일.md` (예: `journal/2026/2026-11-16.md`)
- **템플릿**: [_template.md](_template.md)를 복사해서 시작
- **커밋**: 하루 한 번, 메시지는 `journal: 2026-11-16 0-1 벡터 연산` 형식. 일지는 브랜치를 만들지 않고 `main`에 바로 커밋·푸시한다 (로드맵·ADR 같은 문서 수정은 브랜치에서 작업)
- 공부를 못 한 날은 쓰지 않아도 된다. 빈 기록을 억지로 채우지 않는다
