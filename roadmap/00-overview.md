# 전체 지도

## 1. 목표

- XR의 몰입감·현실감을 높이는 기술이 **어떤 원리로 동작하는지** 이해한다
- 새 기술과 논문을 보고 **스스로 판단할 수 있는 능력**을 기른다
- 그 기반이 되는 **수학**(선형대수, 사영 기하, 확률, 신호처리, 최적화)을 제대로 공부한다
- 주력 분야는 **실시간 렌더링**이다. AAA 게임 렌더링과 XR 렌더링은 같은 기술의 다른 응용이다

## 2. XR 시스템 지도: 각 분야의 위치

```
  [트래킹: 입력]  →  [렌더링: 계산]  →  [디스플레이: 출력]  →  [인간 지각]
        ↑                                                         │
        └────────── 고개를 돌림 (이 루프 전체가 약 20ms 안에) ──────┘
```

| 분야 | 이 저장소에서의 트랙 | 렌더링과의 관계 |
|---|---|---|
| 렌더링 | **주력** | 중심 |
| 트래킹 (자세 예측) | 연결 | Timewarp·재투영에 예측된 자세가 필요하다 |
| 지각 (주변시야, 시선) | 연결 | Foveated rendering의 품질 기준을 정한다 |
| 디스플레이·광학 | 교양 | 렌더링이 맞춰야 할 조건(해상도, 주사율, 렌즈 왜곡)을 정한다 |
| SLAM, Presence, AR 이론 | 교양 | 기술 판단을 위한 배경 지식 |

## 3. 진행 순서

```
주력  0.수학 기반 → 1.래스터화 → 2.샘플링 → 3.셰이딩·빛 → 4.실시간 기법 ──→ 5.XR 렌더링 → 6.뉴럴 렌더링
                                                                    ↑
연결                                                B1.칼만 필터·자세 예측
                                                    B2.시선 추적 / B3.주변시야 지각 ──┘

교양  (병행) 가벼운 논문·책 읽기: VR 전반 → 디스플레이 기초 → SLAM → Presence ...
```

- 주력 트랙은 **순서대로** 진행한다. 앞 단계의 수학이 뒤 단계의 전제다
- 연결 트랙은 **주력 5단계 직전**에 공부한다
- 교양 트랙은 주력 트랙과 **병행**한다. 주력 공부가 막혔을 때 쉬어 가는 읽기로 써도 좋다

|---|---|---|
| 주력 | 0. 수학 기반 | 🟨 진행 중 (2026-11-16 시작) |

| 주력 | 2. 샘플링과 신호처리 | ⬜ 시작 전 |
| 주력 | 3. 셰이딩과 빛의 물리 | ⬜ 시작 전 |
| 주력 | 4. 실시간 렌더링 기법 | ⬜ 시작 전 |
| 주력 | 5. XR 렌더링 | ⬜ 시작 전 |
| 주력 | 6. 뉴럴 렌더링 | ⬜ 시작 전 |
