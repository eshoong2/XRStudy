# ADR 0001: 주력 분야로 실시간 렌더링을 선택

- **상태**: 승인
- **날짜**: 2026-11-16

## 배경

XR의 몰입감·현실감을 높이는 기술을 이해하고, 기술을 판단하는 능력을 기르는 것이 목표다. XR 연구 분야는 크게 디스플레이·광학, 트래킹·SLAM, 렌더링, 지각, 상호작용으로 나뉜다. 모두를 같은 깊이로 공부하기에는 범위가 너무 넓어서 주력 분야를 정해야 했다.

고려한 조건:
- 수학을 좋아하고, 수학적으로 깊이 공부하고 싶다
- C++ 기반 실시간 게임 개발을 공부해 왔다
- 게임 개발 취업을 준비 중이다

## 비교한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| 디스플레이·광학 | VAC처럼 이 분야만 풀 수 있는 문제가 있다 | 기초 지식이 없고, 게임 개발 경력과 연결이 약하다 |
| 지각·상호작용 | 몰입 이론(Presence, Embodiment)의 중심이다 | 처음 기대한 방향과 달랐고, C++ 비중이 낮다 |
| 트래킹·SLAM | "C++ + 수학" 조합이 가장 많이 겹친다 (확률 추정, 최적화, 리 군) | UE5·게임 경력과의 연결이 약하고, 게임 업계 수요가 적다 |
| **실시간 렌더링** | 수학 비중이 크고, AAA 게임 렌더링과 XR 렌더링이 같은 기술의 다른 응용이다. C++·UE5 경험과 연결된다 | 렌더링 프로그래머는 채용 인원이 적고 신입 요구 수준이 높다 |

## 결정

**실시간 렌더링을 주력 분야로 한다.** 다른 분야는 버리지 않고 깊이를 나눠 유지한다.

- **연결**: XR 렌더링에 직접 필요한 자세 예측, 시선 추적, 주변시야 지각
- **교양**: 기술 판단을 위한 SLAM, Presence, 디스플레이 기초
- **보류**: SLAM 구현 심화, 광학 설계, 지각 실험 연구

## 이유

- AAA 렌더링 기법(TAA, 프레임 생성, VRS)과 XR 렌더링 기법(Timewarp, Spacewarp, Foveated rendering)이 같은 원리(재투영, 선택적 셰이딩)를 공유한다. 그래서 XR 이해와 취업 준비가 같은 공부로 이어진다
- XR 시스템은 병목이 이동하는 구조라서, 렌더링을 이해하려면 결국 트래킹(자세 예측)과 지각(Foveation 기준)도 알아야 한다. 연결 트랙으로 이를 보완한다

## 결과

- 주력 트랙은 수학 기반 → 래스터화 → 샘플링 → 셰이딩 → 실시간 기법 → XR 렌더링 → 뉴럴 렌더링 순서로 진행한다
- 렌더링 프로그래머 채용의 높은 요구 수준은 수학적 이해의 깊이와 이해 확인용 구현으로 대응한다
