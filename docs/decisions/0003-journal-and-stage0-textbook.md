# ADR 0003: 공부 일지 위치와 0단계 주 교재

- **상태**: 승인
- **날짜**: 2026-11-16

## 1. 공부 일지 위치

### 비교한 대안

| 대안 | 수식 | 장점 | 단점 |
|---|---|---|---|
| **A. XRStudy 저장소 `journal/`** | ✅ | 로드맵·노트와 한곳에 모이고, 매일 커밋이 꾸준함의 기록이 된다 | 블로그만큼 노출되지 않는다 |
| B. Velog | ✅ | 작성이 쉽고 국내 개발자에게 익숙하다 | 노트와 기록이 두 곳으로 나뉜다 |
| C. Tistory | △ | 디자인 자유도가 높다 | 수식 설정이 번거롭다 |
| D. GitHub Pages 블로그 | ✅ | 완전한 자유도 | 처음 구축에 시간이 든다 |
| E. Notion | ✅ | 가장 편하다 | Git 기록과 분리되고, 공개용으로 약하다 |

### 결정

**A**. 매일의 기록은 `journal/`에 쓰고, 정리된 개념은 `notes/`에 둔다. 블로그는 나중에 잘 정리된 주제만 골라 올릴 때 다시 정한다. 저장소는 Public으로 전환한다.

## 2. 0단계 주 교재

### 비교한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| **A. *3D Math Primer* + 3Blue1Brown** | 0단계 주제와 정확히 일치하고, 무료로 공개되어 있다 | 고유값, SVD 같은 일반 선형대수는 얕다 |
| B. Strang *Introduction to Linear Algebra* | 수학적으로 탄탄하고, 나중의 최소제곱·최적화의 기반이 된다 | 투영, 쿼터니언 같은 3D 그래픽스 주제는 다루지 않는다 |
| C. Lengyel *Foundations Vol. 1* | 짧고 밀도가 높다 | 처음 공부하는 교재로는 압축이 심하다 |

### 결정

**A**. 자가 진단 결과 0-1~0-7 대부분이 "처음이거나 잘 모름" 수준이므로, 직관(3Blue1Brown)을 먼저 잡고 범위가 딱 맞는 교재(3D Math Primer)로 들어간다. Strang은 참고서로 두고 더 깊이 보고 싶은 주제만 본다.
