# XRStudy

XR(VR/AR/MR)의 **몰입감과 현실감을 높이는 기술**을 이해하고, 그 기술을 **스스로 판단할 수 있는 능력**을 기르기 위한 학습 저장소입니다.

이 저장소의 목표는 프로젝트를 완성하는 것이 아닙니다. **기술에 대한 이해와 수학 공부**가 목표이고, 주된 학습 방법은 다음 두 가지입니다.

- **수학책·교재 공부**: 개념을 이해하고 손으로 유도한다
- **논문 읽기**: 기술이 *왜* 나왔고, 무엇을 해결했고, 무엇을 희생했는지 판단한다

코드 구현은 목적이 아니라 **이해를 확인하는 도구**로 씁니다. "식을 코드로 옮겼을 때 예상대로 동작하는가"가 이해했는지를 확인하는 가장 확실한 방법이기 때문입니다.

## 참고 문헌에 대해

로드맵의 책과 논문 목록은 AI(Claude)와의 대화에서 정리한 것입니다. 일부 서지 정보(저자, 연도, 학회)가 부정확할 수 있으므로 **읽기 전에 원문으로 확인**하고, 확인한 항목은 체크합니다.

## AI 활용 방식

이 저장소는 AI(Claude Code)를 **학습 보조**로 활용합니다.

- **AI가 하는 일**: 분야 지도와 로드맵 초안 제안, 개념 설명, 대안 비교와 추천, 문서 구조 작성
- **내가 하는 일**: 학습 방향과 우선순위 결정, 수식 유도와 노트 작성, 논문 분석, 이해 확인용 구현
- **원칙**: AI의 설명은 출발점일 뿐이고, 책·논문 원문으로 검증한다. 결정 사항은 [docs/decisions/](docs/decisions/)에 근거와 함께 남긴다.
