# 개념 노트

책과 논문으로 공부한 개념을 정리합니다. 새 노트는 [_template.md](_template.md)를 복사해서 시작합니다.

| 폴더 | 내용 |
|---|---|
| `math/` | 선형대수, 사영 기하, 확률, 신호처리, 최적화 |
| `rendering/` | 래스터화, 샘플링, 셰이딩, 실시간 기법, XR 렌더링 |
| `tracking/` | 칼만 필터, 자세 예측, SLAM |
| `perception/` | 주변시야, 정신물리학, Presence, 멀미 |
| `display/` | 디스플레이·광학 기초 |

폴더는 첫 노트를 쓸 때 만듭니다.

**파일 이름 규칙**: `주제-이름.md` (예: `math/homogeneous-coordinates.md`, `rendering/perspective-correct-interpolation.md`)
